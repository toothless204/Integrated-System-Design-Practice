PPST II — Integrated Manufacturing System Improvement

This repository contains the documentation of the Integrated System Design Practicum II (TI2092) project. The project focuses on analyzing and improving the manufacturing system of PT PPST Manufacturing, a simulated manufacturing company that produces tripod components.

The project integrates data acquisition, work system mapping, manufacturing automation, production data management, ergonomics evaluation, and work time standardization to improve operational efficiency, data accuracy, operator comfort, and production productivity.

Project Overview

PT PPST Manufacturing faces several operational problems in its tripod production process. These problems include manual production data recording, inefficient material flow, manual visual inspection, non-integrated production data, ergonomic risks, and workplace environmental conditions that may reduce operator performance.

This project applies an integrated industrial engineering approach to evaluate the existing production system and propose improvements across multiple areas of manufacturing operations.

Objectives

The main objectives of this project are:

To design an automatic data acquisition system for more accurate and real-time production recording.
To map and improve the existing work system using industrial engineering tools.
To develop a manufacturing automation concept for product inspection.
To integrate production datasets for easier access, monitoring, and analysis.
To evaluate ergonomics, anthropometry, biomechanics, work physiology, mental workload, and visual display aspects.
To determine standard work time based on cycle time, performance rating, and allowance factors.
To propose improvement recommendations that increase productivity, operator comfort, and production consistency.

Methodology

The project follows a structured improvement methodology:

1. Manufacturing Process Understanding

The production process is analyzed by identifying the main work elements, including loading, processing, unloading, material handling, and inspection. This step helps define the current production flow and identify activities that add value and activities that create waste.

2. Data Acquisition Analysis

The project compares manual data recording with automatic data acquisition. The proposed approach uses sensors and microcontrollers to record production data more accurately and efficiently.

3. Work System Mapping

The existing work system is mapped using tools such as Flow Diagram and Worker-Machine Chart. This step is used to identify inefficient movement, waiting time, unnecessary checking, and other non-productive activities.

4. Root Cause Analysis

Several problem-solving tools are used to identify the root causes of productivity issues, including 7 Quality Tools, 5 Whys, and 5W1H analysis.

5. Manufacturing Automation Design

The project develops a concept for automated product inspection. The automation system is designed to reduce dependence on manual visual inspection by using sensors and control logic.

6. Production Data Integration

Production data is organized and integrated to support easier monitoring, analysis, and decision-making. This helps create a more reliable data foundation for production improvement.

7. Ergonomics Evaluation

The project evaluates workstation design, operator posture, physical workload, mental workload, visual display, and required rest time. The goal is to reduce injury risk, fatigue, and discomfort during work.

8. Work Measurement and Standardization

The project calculates cycle time, normal time, standard time, performance rating, and allowance factors. This step supports fair and realistic production target setting.

9. Improvement Recommendation

The final stage is to develop practical recommendations for improving the production system, operator comfort, work efficiency, and production consistency.

Key Findings

The main findings from this project are:

Manual production recording may lead to data errors, delayed recording, and reduced operator efficiency.
Work flow and tool placement are not fully optimized, causing unnecessary motion, reaching, checking, and handling time.
Manual visual inspection is not sufficient to detect all potential product defects.
Sensor-based automation can improve inspection consistency and reduce operator dependency.
Production data needs to be integrated to support monitoring, evaluation, and data-driven decision-making.
Workstation design, working posture, visual display, physical workload, and mental workload need systematic evaluation to reduce fatigue and injury risk.
Physical work environment factors such as lighting, temperature, humidity, noise, air movement, odor, and dust can affect operator comfort and productivity.
Work time standardization is important to establish realistic production targets and fair workload allocation.
