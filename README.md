# Integrated System Design Practice

This repository documents a complete series of **Integrated System Design Practice** projects, covering **PPST I, PPST II, PPST III, and PPST IV**. The projects represent a progressive industrial engineering learning path, starting from product and process realization, continuing to work system improvement and production control, and ending with facility layout design and investment feasibility analysis.

## Overall Project Flow

The PPST series follows the logic of an integrated manufacturing system:

```text
PPST I   → Product and process realization
PPST II  → Work system improvement and shop floor integration
PPST III → Production planning, quality control, and decision support system
PPST IV  → Facility layout design and factory investment analysis
```

Each stage builds on the previous one. PPST I establishes the product and manufacturing foundation. PPST II improves the work system and shop floor operations. PPST III develops planning, quality, and decision-support capabilities. PPST IV integrates the whole system into a feasible factory layout and investment plan.

## PPST I — Product and Process Realization

PPST I focuses on the early stage of manufacturing system realization. The main objective is to transform a product concept into a manufacturable product through technical design, process planning, and physical production output.

The project covers product part design, CAD modeling, assembly design, operation planning, machine selection, and the production of physical components.

### Main Activities

* Designing product parts and assembly using CAD.
* Creating technical drawings and part documentation.
* Developing the Operation Process Chart.
* Planning production routes and machine requirements.
* Producing physical parts based on the designed system.
* Coordinating team-based manufacturing project execution.

### Main Outputs

* CAD models for each part.
* CAD assembly model.
* Operation Process Chart.
* LRP / production planning documentation.
* Machine requirement analysis.
* Physical manufactured product or component prototype.

## PPST II — Work System Improvement and Shop Floor Integration

PPST II focuses on improving the existing manufacturing work system. The project analyzes how work is performed on the shop floor and improves the system through data acquisition, work mapping, automation, ergonomics, production data management, and work time standardization.

The main goal is to improve operational efficiency, reduce human error, improve operator comfort, and create a more data-driven production system.

### Main Activities

* Designing automatic data acquisition using sensors and microcontrollers.
* Mapping and improving the work system using industrial engineering tools.
* Identifying waste, inefficient motion, and non-value-added activities.
* Designing automation concepts for manufacturing inspection.
* Managing and integrating production data.
* Evaluating ergonomics, posture, workload, and visual display.
* Calculating standard work time and evaluating physical work environment conditions.

### Main Outputs

* Sensor-based data acquisition concept.
* Flow Diagram and Worker-Machine Chart.
* Root cause analysis using 7 Quality Tools, 5 Whys, and 5W1H.
* Arduino and Tinkercad-based automation design.
* Production data management documentation.
* Ergonomics evaluation and improvement recommendation.
* Standard time calculation and work environment analysis.

## PPST III — Production Planning, Quality Control, and Decision Support System

PPST III focuses on planning, controlling, and supporting decisions in a production system. The project connects demand forecasting, assembly line balancing, statistical quality control, acceptance sampling, database modeling, and dashboard-based decision support.

The main goal is to convert production and quality data into better operational decisions.

### Main Activities

* Forecasting market demand using quantitative forecasting methods.
* Designing and evaluating an assembly line based on demand and standard time.
* Identifying bottlenecks and balancing workstations.
* Applying statistical quality control using control charts.
* Calculating process capability, OC Curve, and Average Run Length.
* Designing acceptance sampling plans for supplier components.
* Extracting and processing quality data using SQL.
* Modeling manufacturing data using ERD, LDM, PDM, and normalization.
* Building a shop floor-level Decision Support System using Microsoft Power BI.

### Main Outputs

* Demand forecasting model and forecast performance evaluation.
* Assembly line design and line balancing analysis.
* Control charts and process capability analysis.
* OC Curve and ARL analysis.
* Single and double acceptance sampling plans.
* Dodge-Romig and Military Standard sampling comparison.
* SQL query documentation.
* Data model documentation.
* Power BI dashboard and DSS prototype.

## PPST IV — Facility Layout Design and Factory Investment Analysis

PPST IV focuses on designing a complete factory layout and evaluating whether the proposed manufacturing facility is operationally and financially feasible. The project uses Systematic Layout Planning to connect demand, machine requirements, space requirements, material handling cost, department relationships, layout optimization, and investment feasibility.

The main goal is to design a factory that is efficient, feasible, and financially justifiable.

### Main Activities

* Estimating market demand for the proposed factory.
* Creating Assembly Chart, Routing Sheet, and Multi Product Process Chart.
* Calculating machine requirements and production area requirements.
* Calculating space requirements for production, warehouse, receiving, shipping, and supporting facilities.
* Calculating Material Handling Cost.
* Creating flow, weight, cost, and priority matrices.
* Designing Activity Relationship Chart.
* Designing Activity Relationship Diagram.
* Designing Area Allocation Diagram.
* Improving factory layout using layout optimization methods.
* Comparing alternative layouts using OMH and feasibility criteria.
* Evaluating factory investment using financial feasibility metrics.

### Main Outputs

* Demand estimation.
* Assembly Chart.
* Routing Sheet.
* Multi Product Process Chart.
* Machine requirement calculation.
* Floor space requirement calculation.
* Material Handling Cost analysis.
* ARC, ARD, and AAD.
* Initial factory layout.
* Improved factory layout using CRAFT, WinQSB, Excel Add-ins, Python, and manual calculation.
* Layout comparison based on OMH.
* Investment feasibility analysis.
* NPV, IRR, Payback Period, and cash flow evaluation.

## Integrated Learning Outcome

Through PPST I to PPST IV, this repository demonstrates the full cycle of industrial engineering system design:

1. Product and process design.
2. Shop floor work system improvement.
3. Production planning and quality control.
4. Data-driven decision support.
5. Facility layout optimization.
6. Factory investment feasibility analysis.

## Summary
