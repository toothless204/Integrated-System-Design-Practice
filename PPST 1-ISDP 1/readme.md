# Manufacturing Product Development — PPST 1

This repository documents a manufacturing product development project created for PPST 1. The project covers the end-to-end development of a physical product, starting from system selection, part design, CAD modeling, assembly design, process planning, machine selection, CNC programming, and final product realization.

The final output of this project includes CAD models for each component, assembly design, Operation Process Chart (OPC), Layout/Process Planning documentation, machine planning, CNC machining files, and a physical patterned workpiece.

---

## Project Overview

This project was developed as a practical manufacturing engineering exercise. The main objective was to transform a product concept into a manufacturable object through structured engineering stages.

The project focuses on:

* Product and component design
* CAD modeling for individual parts
* Assembly planning
* Manufacturing process planning
* CNC machining preparation
* G-code generation
* Final physical product realization

This repository is intended to show how manufacturing theory, CAD design, process planning, and machining execution can be integrated into one complete product development workflow.

---

## Product Scope

The product was developed through several main components and manufacturing files, including:

| Component / File       | Description                                                            |
| ---------------------- | ---------------------------------------------------------------------- |
| Upper Base Plate       | Structural base component used as part of the assembly                 |
| Stripper               | Supporting component for the product mechanism and manufacturing setup |
| Blank Punch            | Punch component used in the forming/cutting system                     |
| CAD Models             | 3D design of each part and the final assembly                          |
| G-code Files           | CNC machining instructions for manufacturing selected components       |
| OPC                    | Operation Process Chart for mapping the manufacturing process          |
| LRP / Process Planning | Planning documentation for production flow and machine utilization     |

The project produced several engineering deliverables:

1. **CAD Design**

2. **Process Planning**

   * Machine and tooling consideration

3. **CNC Machining Files**

   * G-code for selected components
